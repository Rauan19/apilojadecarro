# DESIGN.md

## World
Marketplace Webmotors aplicado a todo o frontend:
- Primário vermelho `hsl(357 78% 50%)` / `#E31C23`
- Fundo cinza claro; cards e painéis brancos
- Tipografia: Archivo (display) + Source Sans 3 (corpo)
- CTAs vermelhos; preços em destaque vermelho na vitrine

## Surfaces
- Login, sidebar, header e páginas do painel usam o mesmo token set
- `/loja` replica a gramática de busca + grade de anúncios + detalhe sticky
