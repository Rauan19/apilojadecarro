# DESIGN.md

## World
EstoqueAuto — marketplace automotivo premium:
- Primário vermelho `hsl(357 78% 50%)` / `#E31C23`
- Charcoal de marca `#12141A`
- Fundo cinza claro; cards e painéis brancos
- Tipografia: Archivo (display) + Source Sans 3 (corpo)
- Marca: `BrandLogo` + mark em `/brand/estoqueauto-mark.png` e `/favicon.svg`

## Surfaces
- Login: coluna de formulário seca (bordas retas, sem glow) + foto full-bleed com faixa vermelha; marca tipográfica no rodapé da foto
- Sidebar, header e páginas do painel usam o mesmo token set
- `/loja` replica a gramática de busca + grade de anúncios + detalhe sticky
